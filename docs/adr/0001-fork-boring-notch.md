# Fork boring.notch rather than build from scratch

SimpleNotch is a fork of [boring.notch](https://github.com/TheBoredTeam/boring.notch) because the goal is to reproduce its design and animations exactly, and only its own code does that. Features borrowed from [Cyclop](https://github.com/akalikbergenov/cyclop) (MIT) are ported into the fork. As a consequence, SimpleNotch is licensed GPL-3.0 and must stay so.

## Considered Options

- **Clean-room rewrite imitating boring.notch's look**: gives a free choice of license and a smaller codebase, but the animations would only be approximated. Rejected.
